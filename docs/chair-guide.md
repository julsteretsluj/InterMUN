# InterMUN guide for chairs

A day-of playbook for running committee in InterMUN. This is product how-to, not a full Rules of Procedure manual — keep your conference RoP open beside it.

---

## 1. Getting set (before first session)

1. Sign in with your chair account.
2. Join the committee with the **room code** (six characters). Do **not** share placard/allocation passwords as the room gate.
3. Open **Prep checklist** and work through rules, topic, tech, and co-chair roles.
4. Confirm seats in **Delegates** (allocation matrix). Matrix edits are usually SMT-owned; chairs use it read-only unless told otherwise.
5. Open **Digital Room** once to check placards and roll status.
6. Bookmark **Guides** and **Official links** for your committee.

**Digital Room vs Committee room**

- **Digital Room** — chair placard board, private compliment/concern/reminder flags, speaker list controls.
- **Committee room** — full live floor that delegates also see (timers, announcements, request to speak).

---

## 2. Day-of floor order

Use this sequence unless your RoP says otherwise.

### 1) Start session
Open **Session** and start the committee session so the shared session clock is live.

### 2) Roll call
Mark **present**, **present & voting**, or **absent**. Watch quorum before substantive votes.

### 3) Opening speeches
Open **Opening speeches**.

- Builds the speakers list **A→Z** automatically.
- Sets a **60 second** per-speaker timer (paused until you Start).
- First speaker is marked current; advance from the list controls.
- To go to **90 seconds**, entertain and pass **Motion to Extend Opening Speech Time** under Formal motions.
- Discipline-blocked seats are skipped.

The same speaker list syncs to Speakers, Digital Room, Committee room, and the floor status bar.

### 4) Speakers (GSL / caucuses)
After openings, use **Speakers** for GSL and moderated lists.

- Add / remove / reorder / set Current / Advance.
- Delegates can also **Request to speak** when you allow it.
- Prefer the speakers list over typing names into the timer.

### 5) Formal motions
Under **Formal motions**:

- Entertain motions from the floor.
- Use presets (open GSL, moderated/unmoderated caucus, open/close debate, extend opening speech, etc.).
- Record Yes / No / Abstain and close the vote.
- Passed moderated caucus / open GSL prompts you to build the speakers list.

**Formal motions vs Motions & Points**

- **Formal motions** = real procedural votes on the floor.
- **Motions & Points** (if your event uses the log) = scratch / SEAMUN-style notes — not a substitute for formal votes.

### 6) Timer
Use **Timer** for floor presets and pause reasons.

- Speakers and current/next names come from the **speakers list**.
- Use per-speaker mode for GSL / opening / moderated speaker times.
- Pause with a reason when debate stops mid-speech.

### 7) Agenda
Switch the **live topic** when the committee moves to the next agenda item. Floor tools follow that topic row.

### 8) Announcements
Pin short dais lines so they show in the digital / committee room.

### 9) Voting
Open votes with the correct majority. Chairs record placards from Session; delegates use the Voting view.

### 10) Discipline (sparingly)
Warnings → strikes → rights restrictions (no vote / no speak / removed). Log a clear reason every time.

---

## 3. Documents mid-session

- **Resolutions / amendments** — review drafts before substantive debate and voting.
- **Notes moderation** — hold, release, or bounce notes when the event enables moderation.
- **Crisis tools** — only for crisis committees (slides, FWC directives/map/backroom as applicable).

---

## 4. Wrap-up

1. Tick **Session progress** stages as you go (opening → caucuses → writing → amendments → voting → superlatives). Each check can share a note with SMT.
2. Complete **Score / Awards** (rubric, nominations) and submit when required.
3. Stop the committee session.
4. Leave documents in **Archive** / Documents as directed by SMT.

---

## 5. Quick reference

### Typical speaking times (confirm with your RoP)

| Mode | Default in InterMUN |
|------|---------------------|
| Opening speeches | 60s; extend to 90s by motion |
| GSL / general speaker | Often 60s per speaker (set on Speakers / Timer) |
| Moderated caucus | Total minutes + per-speaker seconds on the motion |

### Who does what

| Task | Chair | SMT |
|------|-------|-----|
| Run floor (roll, speakers, motions, timer) | Yes | Oversight |
| Room codes / allocation matrix | Use | Own / reset |
| Awards submit | Nominate / score | Receive |
| Conference guides & RoP PDFs | Read | Upload / edit |

### Troubleshooting

| Problem | Try this |
|---------|----------|
| Empty speaker list after openings | Wait for allocations to load, then **Set A–Z list · 60s timer** again |
| Digital Room list ≠ Speakers | Both should follow the **live topic**; refresh the page; change topic only from Agenda |
| Timer not counting | Confirm session is started; press Start on the speaker clock; check it is not paused |
| Delegates cannot join | Share the **room code**, not placard passwords |
| Wrong committee tools | Confirm active conference in Profile / room code |

---

## 6. Suggested session timeline

1. Open → roll call  
2. Opening speeches (A–Z, 60s)  
3. Motions → GSL or moderated caucus  
4. Unmoderated / consultation as needed  
5. Resolution writing  
6. Resolution debate / for–against  
7. Amendments  
8. Voting procedure  
9. Awards / closing  

Tick the matching stages in **Session progress** so SMT can follow along.

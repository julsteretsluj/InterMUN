What chairs do in InterMUN

Resolutions, amendments, notes moderation.

Session progress, awards, stop session, archive.

Before first session

Getting set

  • Room code — six characters to join the committee (not placard passwords).
  • Prep checklist — rules, topic, tech, co-chair roles.
  • Delegates — confirm seats on the allocation matrix (usually SMT-owned).
  • Digital Room — placards, roll status, private chair flags.
  • Guides & official links — RoP and research for your chamber.

Surfaces

Digital Room vs Committee room

Digital Room

Chair placard board, compliment / concern / reminder flags, speaker list controls on this device.

Committee room

Full live floor delegates see — timers, announcements, request to speak, shared status.

The speaker list is the same everywhere: Speakers, Opening speeches, Digital Room, and the committee floor.

Day of

Suggested floor order

Start session→ Roll call→ Opening speeches→ Speakers→ Motions→ Timer
Agenda→ Announcements→ Voting→ Discipline→ Wrap-up

Follow your RoP; InterMUN just keeps the tools in one place.

Floor

Session start & roll call

  • Start session — turns on the shared committee session clock.
  • Roll call — present, present & voting, or absent.
  • Watch quorum before substantive votes.
  • Top status bar shows session time and the current speaker when one is set.

Floor

Opening speeches

  • One-click A→Z speakers list for every eligible delegation.
  • Default 60s per speaker (paused until you Start).
  • First speaker marked current; advance from list controls.
  • Extend to 90s by passing Motion to Extend Opening Speech Time.
  • Discipline-blocked seats are skipped automatically.

Floor

Speakers list (GSL & caucuses)

  • Add, remove, reorder, set Current, and Advance.
  • Delegates can Request to speak when you allow it.
  • After a moderated caucus or open GSL passes, InterMUN prompts you to fill the list.
  • Prefer the list over typing names into the timer — names stay synced.

Floor

Formal motions

  • Entertain motions; use presets (GSL, mod/unmod, open/close debate, extend opening speech…).
  • Record Yes / No / Abstain and close the vote.
  • Competing motions follow disruptiveness order.

Formal motions = real votes on the floor. A Motions & Points log (if used) is scratch notes — not a substitute.

Floor

Timer

  • Floor presets for speeches and caucuses; pause with a reason.
  • Per-speaker mode for GSL, openings, and moderated speaker times.
  • Current / next speaker come from the speakers list.
  • Delegates see the live clock in the committee room and status bar.

Floor

Agenda & announcements

Agenda

Switch the live topic when debate moves on. Motions, timers, and speakers follow that topic row.

Announcements

Pin short dais lines so they appear in Digital Room and the committee room.

Floor

Voting & discipline

Voting

Open votes with the right majority. Chairs record placards from Session; delegates use Voting.

Discipline

Warnings → strikes → rights (no vote / no speak / removed). Use sparingly; always log a reason.

Live board

Digital Room features

  • Searchable placard grid with roll status.
  • Add a placard to the shared speaker list in one tap.
  • Private compliment / concern / reminder flags (synced for chairs on that committee).
  • Jump to full committee room or the delegates matrix when needed.

Mid-session

Documents & crisis

  • Resolutions / amendments — review drafts before substantive debate and voting.
  • Notes moderation — hold, release, or bounce notes when enabled.
  • Crisis tools — slides, FWC directives / map / backroom only when your committee uses them.

Close

Wrap-up

  • Session progress — tick stages (opening → caucuses → writing → voting → superlatives); SMT can see updates.
  • Score / Awards — rubric, nominations, submit when required.
  • Stop session — end the shared session clock.
  • Leave files in Archive / Documents as directed by SMT.

Remember

Quick tips

  • One speakers list drives Speakers, Opening speeches, Digital Room, and the floor bar.
  • Share the room code, not placard passwords, for committee join.
  • Empty speaker chip in the top bar means nobody is current — that’s intentional.
  • Full written playbook: Guides → InterMUN guide for chairs.
